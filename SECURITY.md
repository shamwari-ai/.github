# Security policy

## Reporting a vulnerability

**Do not open a public issue.** Report privately through GitHub Security
Advisories:

<https://github.com/shamwari-ai/.github/security/advisories/new>

If that is not available to you, email **<security@shamwari.ai>** and expect
an acknowledgement within three working days.

Include what you can: the affected component, a reproduction, and the impact
you believe it has. A partial report sent early is more useful than a
complete one sent late.

## Scope

In scope:

| Component                            | Surface                                                             |
| ------------------------------------ | ------------------------------------------------------------------- |
| `shamwari-gateway`                   | The edge Worker: routing, scope enforcement, auth token handling    |
| `shamwari-core`                      | The FastAPI service: `resolve_scope`, key verification, data access |
| `shamwari-web` / `shamwari-platform` | The public site and the customer console                            |
| `shamwari-ai/docs`                   | The documentation site                                              |

Out of scope: findings against third-party inference providers themselves,
volumetric denial of service, and reports generated by a scanner with no
demonstrated impact.

## What we consider most serious

Two properties matter more than anything else here, and a break in either is
treated as critical regardless of how it is reached:

1. **`personal`-scope data must never reach a third-party inference
   provider.** The gate is deliberately implemented twice — once in the
   Worker (`gateway/src/scope.ts`, fails fast) and once in Core
   (`core/main.py::resolve_scope`, authoritative). A report showing the two
   disagree is a rule 1 finding even if neither alone looks exploitable.
2. **The premium tier must stay `licenseClass: restricted`.** Anything that
   causes a restricted class to be stamped, stored, or served as
   unrestricted is in scope.

## Disclosure

We will confirm the report, agree a timeline with you, and credit you in the
advisory unless you ask otherwise. Please give us a reasonable window to
ship a fix before publishing.
